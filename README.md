# Ledyard — Story Slideshow

Public, mobile-first slideshow telling the history of the 1874 Ledyard Block
(Grand Rapids) and its return to residential use. Built by CWD Real Estate
Investment / Paschka Studio.

Linked via a dedicated QR code (separate from the window-vinyl QR, which
points at the main CWD Ledyard page). Scroll or swipe through — no accounts,
no build step, single static `index.html`.

Live: https://ajpaschka.github.io/cwd-ledyard-story/

Source content: `CWD Projects/Ledyard/building-history-research.md` (AJAI).
Brand: Ledger palette, Fraunces/Barlow, per `_shared/typst/themes/ledyard.typ`.
